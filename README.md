# CineTrack

A responsive web application designed to help users discover, track, and bookmark their favorite TV shows and actors. 

## Features
* **Dynamic Search:** Seamlessly switch between searching for TV Shows and Actors.
* **Shuffle Feed:** Discover new content instantly with the Shuffle feature.
* **Personalized Tracking:** Bookmark your favorite items and maintain a "Must Watch" list.
* **Responsive Design:** Optimized for both desktop and mobile devices with a custom drawer-style navigation.
* **Data Persistence:** Uses LocalStorage to save your bookmarks across sessions.

## Technologies Used
* HTML5 & CSS (Tailwind CSS)
* JavaScript (ES6+)
* TVMaze API

## How to Run
1. Clone this repository to your local machine.
2. Open `https://ashyrashy1.github.io/TV-Search-Assignment/` in any modern web browser.

## Project Structure
- `index.html`: Main structure and UI components.
- `script.js`: Core logic for API integration, state management, and event handling.
