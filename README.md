# CINETRACK: TV & Actor Discovery Engine 🎬

A responsive web application designed for tracking television shows and discovering actor filmographies, powered by live data from the TVMaze API.

## Features
- Search for TV shows and view detailed information.
- Responsive design for optimal viewing across mobile, tablet, and desktop devices.
- Efficient data fetching using the TVMaze API.

## Technologies Used
- **HTML5**: Semantic structure for accessibility and modularity.
- **Tailwind CSS**: Utility-first framework for a consistent and responsive UI.
- **Vanilla JavaScript (ES6+)**: Handles application logic, DOM manipulation, and asynchronous data fetching.

This project was developed as part of a technical assignment focusing on:
- Modular, semantic HTML structure.
- Separation of concerns between UI and application logic.
- Asynchronous data handling with the Fetch API.


"Known Limitations."
The TVMaze schedule API returns a limited set of results. In some scenarios, data may appear repetitive upon repeated reloads due to API caching behavior. This was observed during testing and does not impact core functionality.
